## 📂 Featured Projects

### 💧 Water Quality Hotspot Pipeline

A team-built, end-to-end data pipeline that identifies persistent fecal-indicator pollution hotspots (*E. coli* and enterococci) to help prioritize water rehabilitation. It ingests data from 5 independent sources (GEMStat, Eionet, Water Quality Portal, Open-Meteo, Natural Earth), harmonizes it into one schema and unit, validates it at the raw, staging, and curated layers, and loads it into PostgreSQL. An Apache Airflow DAG running in Docker orchestrates the whole flow, and a static dashboard shows a hotspot map and regional priority ranking.

**My role: Data Engineer 1 (Ingestion and Platform).** I built the extractors, the WQP site sampling, the ingestion metadata, the Docker environment, and the Airflow DAG.

**Stack:** Python · pandas · PyArrow · GeoPandas · Apache Airflow · PostgreSQL · Docker · Parquet
